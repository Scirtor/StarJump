Загружаем лунную башню… Первый запуск может занять немного времени.

StarJump всегда под рукой

iPhone / iPad: открой эту страницу в Safari → «Поделиться» → «На экран “Домой”» → включи «Открывать как веб-приложение», если этот пункт есть → «Добавить».

Android: открой страницу в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Для первого запуска нужен интернет. После загрузки игра сохраняется на этом устройстве.

Управление: стрелки / A, D и двойной прыжок на пробел. На телефоне удерживай стрелку одним пальцем, прыгай другим. Можно повернуть экран. Прогресс хранится только в этом браузере.
